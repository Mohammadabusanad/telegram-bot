# Telegram Echo Bot

A simple Telegram bot built with python-telegram-bot that replies to any text message.

## Features
- Replies to user messages instantly
- Secure token storage using environment variables (.env)

## How to Run
1. Install dependencies: 
pip install python-telegram-bot python-dotenv

2. Create a .env file with:
TOKEN=your_bot_token_here

3. Run:
python telegram_bot.py

## Technologies
- Python
- python-telegram-bot
- python-dotenv
